About mcpstat Dashboard

mcpstat is a Python library that records MCP tool, prompt and resource calls, outcomes and latency in local SQLite storage.

mcpstat Dashboard brings those statistics into VS Code. Compare handler usage, review errors and measured latency, and find registered handlers with no recorded calls. The activity chart shows changes observed during your dashboard session.

Connect through VS Code or HTTP to an MCP server with mcpstat installed and tracking configured, or open its existing statistics database.

Add mcpstat tracking to the server

Chat: Manage Tool Approval

VS Code controls confirmations when the dashboard calls a tool outside chat. Pre-approve the selected statistics tool to avoid repeated confirmation dialogs during refresh.

  1. Open the Command Palette and run Chat: Manage Tool Approval.
  2. Find your server's statistics tool: .
  3. Enable pre-approval (without approval), then choose Start auto-refresh.

Editor versions or organization policies may still require confirmation. VS Code instructions

This editor does not provide the approval-management command. You can keep manual refresh or connect directly through HTTP or a statistics database.

Monitor your MCP server

View calls, errors and latency from a server instrumented with mcpstat.

Start your server in VS Code, then choose its get_tool_usage_stats tool, including any server prefix. You can also connect directly to an HTTP MCP endpoint.
