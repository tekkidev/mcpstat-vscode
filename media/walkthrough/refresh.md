# Refresh without repeated interruptions

Use **Refresh** for another observation. Editor connections start manually.
When you choose **Start auto-refresh**, the dashboard explains how to open
**Chat: Manage Tool Approval** and pre-approve only your server's statistics tool.
VS Code versions or organization policies may still require confirmation.

HTTP and database connections start with automatic refresh. Collection pauses when
the dashboard is hidden or closed. After a failed request, use **Refresh** to retry.

The chart shows changes observed during this dashboard session. Cumulative values
come from the server's recorded history.
